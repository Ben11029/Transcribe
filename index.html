【A.使用说明 Instructions】

1.🚀会话前，请先点击"设置"并输入访问码（仅需首次输入），后再填入个人有效付费api（每次需重复输入），再进行使用。（内部测试版，请勿外传！👀）

2.⌨️快捷键操作：启动会话后，按 F9 键，或点击【截断✂️Cut】按钮，分割音频片段。

3.🔑API 密钥配置：进入设置后，您需要自行获取 API 密钥。您可配置 Gemini 的 API 密钥直接使用新一代 Gemini 3.5 智能转录模型 及后续文本校正与翻译（仅需单个 Gemini 密钥即可跑通全流程！）。如需使用 OpenAI 提供的转录或对话模型，可配置 OpenAI 的 API 密钥。API 一般按量计费📊，目前阶段十分便宜💰，且 Gemini 提供免费额度 🎁。

4.🎙️会话稳定性与音频截取：注意保持声源清晰干净，避免多声源。支持麦克风声源，不支持系统内部声源，故一般适合给现场会议或者外部播放源的转录与翻译。根据测试，会话启动后的前一到两段可能会出现不稳定情况，建议您提前截取两段测试音频 🔇，以排除干扰。在对话过程中，请尽量选择在一段完整、连贯的意群停顿处进行截取，要注意避免在句中截断。通常建议将每段音频截取为 3 到 4 句话，这样更适合页面显示，提升用户体验 ✨。

5.⏯️录音暂停与恢复：在不使用录音功能时，您可以选择暂停录音。暂停后，您可以随时方便地重新开始录音，无需从头设置。
